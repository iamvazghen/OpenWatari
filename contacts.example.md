# Contacts (example)

Copy this to `contacts.md` (gitignored, private) and fill in real people. Afon reads it to turn a
name into a send target — "email John" → john@example.com — before any send or draft. Forgiving plain
text, **one contact per line**; the name is the leading text, then any of email / `tg:@handle` /
`tel:+…`. No file at all is fine: name resolution just reports the name is unknown, never crashes.
